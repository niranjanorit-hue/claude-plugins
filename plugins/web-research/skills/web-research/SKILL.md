# Web Research

1. Restate the question in one line and list what would answer it.
2. Read primary sources first (official docs, the project's repo, the original paper), then secondary ones.
3. Read each page with the `fetch` tool. Quote sparingly and always link the source.
4. When sources disagree, say so and say which you trust more and why.
5. Finish with a short answer, then the sources you used.

Requires `uv` installed so `uvx mcp-server-fetch` can run.
